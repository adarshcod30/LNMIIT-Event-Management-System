# Event Hub front end

React 19 single-page app built with Vite and Tailwind CSS. See the [main README](../README.md) for the full project: architecture, security model, API reference and how to run everything.

```bash
cp .env.example .env     # VITE_API_URL must match PORT in backend/.env
npm install
npm run dev              # http://localhost:5173
npm run lint
npm run build
```
